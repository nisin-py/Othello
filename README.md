# Othello

ブラウザで遊べるオセロです。  
対人/対CPU、複数の勝利条件、石ごとの「ひっくり返り回数」表示に対応しています。

## 主な機能

- 対戦形式
  - 対人（同じ画面で交代）
  - 対CPU
- 対CPU時の手番選択
  - 先行（黒）
  - 後攻（白）
  - おまかせ（ランダム）
- 勝利条件
  - 通常オセロ（盤上の石数）
  - 自色の返り回数（盤上の自色石が持つ返り回数の合計）
  - ひっくり返した累計（自分が返した石数の累計）
- 盤面表示
  - 石ごとのひっくり返り回数表示（ON/OFF）
  - カウント表示エリアの折りたたみ

## ファイル構成

- `index.html` : 画面構成（開始前設定・対局画面）
- `styles.css` : スタイル定義
- `game.js` : ゲームロジック/描画/UI制御
- `ai-worker.js` : CPU思考処理（Web Worker）

## 起動方法

### 1) そのまま開く

`index.html` をブラウザで開くとプレイできます。

### 2) ローカルサーバー推奨

Web Worker の制約を避けるため、ローカルサーバーでの実行を推奨します。

例:

```bash
npx serve .
```

表示された `http://localhost:xxxx` を開いてください。

## 操作方法

1. 開始前画面で以下を選択
  - 対戦形式
  - （対CPU時）手番
  - 勝利条件
2. `ゲーム開始` を押す
3. 対局画面で操作
  - 打てるマスをクリックして着手
  - `カウントを非表示/表示` で左パネルを折りたたみ
  - `石のひっくり返し回数を表示` で石上の数字を切り替え
  - `メニューに戻る` で開始前画面へ戻る

## ルール補足

- パスは自動処理です。
- 両者打てる手がない、または盤面が埋まると終局します。
- 引き分け判定あり。

## 開発メモ

- CPU思考は `ai-worker.js` で実行し、UIスレッドのブロックを抑えています。
- Worker の読み込みに失敗した場合はフォールバック処理で対局が止まらないようにしています。
