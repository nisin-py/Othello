# Othello

ブラウザで遊べるオセロです。  
対人/対CPU、複数の勝利条件、灰色石・ライフ制などのバリアントに対応しています。

## 主な機能

### 対戦形式

- **対人** — 同じ画面で交代プレイ
- **対CPU** — CPUと対戦（思考処理は Web Worker で実行）

### 対CPU時の手番

- 先行（黒・先手）
- 後攻（白・後手）
- おまかせ（開始時にランダム）

### 勝利条件

- **通常** — 終局時、盤上の自色の石の数が多い方
- **自色の返り回数** — 終局時、盤上の自色石が持つ「ひっくり返された回数」の合計が多い方
- **ひっくり返した累計** — 終局時、自分の手でひっくり返した相手石の累計が多い方

### バリアント（開始前設定）

- **灰色石** — 盤上の石をすべて灰色表示し、自他の区別をつけにくくする  
  （先手・黒の最初の1手だけ白黒表示）
- **置けるマスのヒント** — 自分のターンに合法手のマスへ印を表示するかどうか
- **ライフ** — なし / 1 / 2 / 3 / 4 / 5  
  ライフ制ON時はどのマスも選べます。石が置けないマスを選ぶと1ライフ減少し、0で即敗北です（先手・黒の最初の1手はライフ減少なし）

### 対局画面の表示設定

- **カウント表示** — 黒/白それぞれの盤上枚数・返り回数・ひっくり返し累計（折りたたみ可）
- **石のひっくり返し回数** — 各石に返り回数の数字を表示するかどうか
- 勝利条件に該当する指標は、色と太字で強調表示されます

## デフォルト設定

| 項目 | デフォルト |
|------|-----------|
| 対戦形式 | 対CPU |
| 手番（対CPU時） | おまかせ（ランダム） |
| 勝利条件 | 通常 |
| ライフ | なし |
| 灰色石 | OFF |
| 置けるマスのヒント | ON |
| カウント表示 | 非表示 |
| 石のひっくり返し回数 | 非表示 |

## ファイル構成

| ファイル | 説明 |
|---------|------|
| `index.html` | 画面構成（開始前設定・対局画面） |
| `styles.css` | スタイル定義 |
| `game.js` | ゲームロジック / 描画 / UI 制御 |

## 起動方法

### 1) そのまま開く

`index.html` をブラウザで開くとプレイできます。

### 2) ローカルサーバー推奨

Web Worker の制約を避けるため、ローカルサーバーでの実行を推奨します。

```bash
npx serve .
```

表示された `http://localhost:xxxx` を開いてください。

## 操作方法

### 開始前

1. 対戦形式・手番・勝利条件・ライフなどを必要に応じて変更
2. **ゲーム開始** を押す

### 対局中

- 打てるマスをクリックして着手  
  （ライフ制ON時はどのマスも選べます）
- **カウントを表示 / 非表示** — 左パネルのスコア詳細を切り替え
- **石のひっくり返し回数を表示** — 盤上の石上数字の ON/OFF
- **メニューに戻る** — 開始前画面へ戻る

ライフ制ON時は、左パネルに ♥/♡ で残りライフが表示されます。

## ルール補足

- パスは自動処理されます。
- 両者打てる手がない、または盤面が埋まると終局します。
- 引き分け判定があります。
- **返り回数** は「その石がひっくり返された回数」です。どの方向から返されたかは得点に関係しません。
- **ひっくり返した累計** は、自分の手番で相手石を返した枚数の合計です。

## 開発メモ

- CPU 思考は `ai-worker.js` で実行し、UI スレッドのブロックを抑えています。
- `file://` 直開きなど Worker 読み込みに失敗した場合も、Blob / インライン Worker へのフォールバックで対局が止まらないようにしています。
- Worker との通信では、手番などの数値型を正規化して型不一致による不具合を防いでいます。
